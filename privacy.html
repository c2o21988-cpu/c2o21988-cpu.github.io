プライバシーポリシー / Privacy Policy

yt-upload（以下「本ツール」）／ 制定日・最終更新日：2026年11月2日
yt-upload ("the Tool") / Effective and last updated: November 2, 2026

1. 本ツールについて / About the Tool

本ツールは、YouTube チャンネルの運営者が自分のチャンネルの動画を管理するためだけに使う個人用ツールです。YouTube API Services を使っています。本ツールを使うことで、YouTube 利用規約に同意したことになります。Google によるデータの扱いは Google プライバシーポリシーをご覧ください。
The Tool is a private tool used solely by the channel owner to manage videos on the owner's own channels. It uses YouTube API Services. By using the Tool you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

2. 使う情報 / Information accessed

  • Google アカウントでの許可（OAuth）の合言葉（アクセストークン・リフレッシュトークン）
    OAuth access and refresh tokens granted by the owner's Google account.
  • 運営者のチャンネルの名前と ID
    The name and ID of the owner's channels.
  • 運営者の動画のタイトル・説明欄・タグ・公開状態・動画 ID
    Titles, descriptions, tags, privacy status and IDs of the owner's videos.

視聴者の情報や、ほかの人のアカウントの情報は使いません。
The Tool does not access any viewer data or any other user's account data.

3. 使い道 / How the information is used

運営者のチャンネルに動画を予約投稿し、タイトル・説明欄・タグを直し、同じ動画を二重に上げないよう一覧を確かめるためだけに使います。広告・分析・販売には使いません。
Only to upload the owner's videos to the owner's channels, update their titles, descriptions and tags, and check the upload list to avoid duplicates. Never used for advertising, profiling or sale.

4. 保存と共有 / Storage and sharing

合言葉（トークン）は運営者のパソコンの中だけに保存し、外部のサーバーには送りません。情報を第三者に渡したり売ったりしません。
Tokens are stored only on the owner's own computer and are not sent to any external server other than Google's. No information is shared with or sold to third parties.

5. 保存期間と削除 / Retention and deletion

トークンは本ツールを使っている間だけ保存し、使わなくなったら削除します。許可はいつでも Google アカウントの「サードパーティによるアクセス」から取り消せます。取り消すと、本ツールは YouTube の情報を使えなくなります。
Tokens are kept only while the Tool is in use and deleted when no longer needed. Access can be revoked at any time via the Google security settings page.

6. Google API のデータの扱い / Google API data

The Tool's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

7. 変更 / Changes

この方針を変えるときは、このページを更新し、上の日付を改めます。
Any changes will be posted on this page with an updated date.
